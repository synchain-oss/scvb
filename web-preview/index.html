关键变体 · loop=none(能力级降级态)

&loop=none 表示宿主不提供循环区:mock 的 setRange("daw_loop") 回 {ok:false, reason:"noLoop"},Range 档位落在灰模已有的 「宿主未提供循环区」disabled + tooltip 占位上。该参数只对 Output 侧有意义(Input 无 Range 档),可挂在上表任一 Output 链接后面;下面是 fixture 表定义的那一个,以及两个常用组合。

  • Output · stereo-mixed & loop=none —— fixture 表定义的降级态基准
  • Output · fifteen-tracks & loop=none —— 健康满配下只缺 loop 能力,便于与默认档逐项对照
  • Output · second-output & loop=none —— daw_loop 代表档失去宿主 loop 后的表现(只读 + 无 loop 双压)

Tab1 分布图双视图([J75] T43)

分布图卡片头部的两态分段控件「分布 ↔ 轨迹」;视图态 = ui.master_chart_mode(新 state 字段,见 docs/contract-changes/20260825-master-chart-mode.md)。 下面这条场景**开箱就落在轨迹档**,并在段表里挖了一段跨轨对齐的缺口 —— 「无分段覆盖的区间不画线」一眼可见。

  • Output · chart-trajectory —— 轨迹档 + 断线缺口;滚轮缩放、拖拽平移,拖过之后右上角出现「回到播放头」
  • Output · fifteen-tracks —— 默认分布档;柱体与 width 横线按轨着色,图例 hover 联动高亮

SCVB Monitor([J75] C · T46)

第三个 VST3 target 的界面:上 = 声像/音量分布图,下 = 轨迹图(占主体),顶部组选择 A–H 为只读 attach(点击换观察对象,不 claim、不影响被观察的组)。整页没有一个写控件。数据来自 web-preview/mock/monitor-mock.js 自拟的 viz 快照事件 —— 真段规格待 T44 定稿(ipc v1.6),形状与字段清单见 web/monitor/viz.js 文件头。

  • Monitor · 在线(组 A · 15 轨) —— 满配:两图齐画、15 色配色、图例 hover 联动
  • Monitor · 空态(组 C 无 Output) —— 观察的组不在线:两张图退出布局,只剩空态说明
  • Monitor · 组切换(开箱停在 B) —— A/B/E 三组在线且轨数不同(15 / 6 / 9),点胶囊即可看出切换生效
  • Monitor · 数据停摆 —— viz 的 publish_ms 冻住 3 秒 ⇒ 琥珀横幅「数据已停更」
  • Monitor · 重连 —— 开箱 attach 失败(Output 还没起),3 秒后段被创建 ⇒ 自动出图,不需要点任何东西
  • Monitor · 版本不匹配 —— 段 abi 高于本机 ⇒ 红横幅 + 停止读取。与「空态」是两条不同的降级路径(J40:拒连,绝不半兼容)
  • Monitor · 缺 vol/width/轨名(T44 v1 的真实形态) —— viz 段里没有分布图要的三条字段 ⇒ 分布图画空、轨迹图照常;补齐前的既定降级态,见 web/monitor/viz-contract.js 的 VIZ_PENDING_TRACK_FIELDS
  • Monitor · 走带停住 —— 播放头不动,便于看静态构图与截图对拍

Range 档位速查(J04:三值枚举,无哨兵)

range.mode 一律取 follow / daw_loop / manual,默认 follow。v0 那套「manual 配一对零值端点表示全曲」的哨兵约定已废除,mock 与 fixture 里不得残留。默认档看 fifteen-tracks,daw_loop 档看 second-output,能力缺失降级看上一节的 loop=none。

?scenario= 兼容口径

05 §2.5 / §3 的场景名同样可用:./output.html?scenario=<名>。已实现的映射到上表 fixture,未实现的回落 fifteen-tracks 并在 console 打一句「场景 {x} 待 T31–T36 接线」——不假装支持。

  • Output(05 §2.5):misaligned · conflict · empty · stale · printing · newer-state · sidecar-missing · no-timeline · project-copy · sidecar-switched · low-sample · print-guard · first-run · recapture-armed · first-run-tour · group-switch · curve-editor · chart-trajectory
