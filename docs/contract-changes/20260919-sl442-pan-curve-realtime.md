## 变更内容

曲线编辑器里画的 pan 角度域增益曲线 `G`,此前只进分析、存盘与界面,没有接进实时音频链。#270 按规格
02 §8.1 步骤 5 把它施加上去:

- `G` 在 dB 域叠加到该声像的音量上(叠加,不替代);
- 查表用的是经全局 width 缩放**之后**的角度;立体声轨的左右两个子声像各查各的;
- 改曲线或换版本时,新旧两张表 30 ms 交叉淡入(时长取 03 §2.4 的切换档),第一次画曲线那一次也淡入;
- `setPanCurve` 提交后改为重建曲线,于是撤销 / 重做、复制版本、载入工程、换版本都走同一条路。

## 兼容性影响

- **从没画过曲线的工程,声音逐位不变**:空曲线 = 0 dB = 增益恰为 1。用例 `CURVE-8`
  (`tests/core/test_pancurve.cpp`)与 `SL442-MIX-1`(`tests/core/test_mix_source.cpp`,mono 与 stereo
  逐位比较、无容差)钉住。
- **画过曲线的工程,声音会变**,变成当初画的样子。这是补上一直没生效的效果,不是回归。
- **曲线点多了三道校验**,共用 `isPanCurvePointUsable`(任一字段非有限、angle 超出 ±100、q 不大于 0
  判不可用;gain_db 只判有限):
  - 解码段表(`CRVS`)时遇到不可用的点,按「字节不可信」判这一节解码失败,不静默修正;
  - 桥面 `setPanCurve` 遇到不可用的点回 `badArg`(此前只比 q 与 angle 的范围,挡不住 NaN,也不查 gain_db);
  - 烘表时再挡一次,不可用就保留上一张表。
- state 布局与 abi、IPC、参数面都不变。
