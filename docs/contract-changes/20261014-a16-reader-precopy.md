## 变更内容

A-5 起 §2「读」写的是:上一代已确认写过、**且新一代不可能写到同一环槽**的尾段继续可读。这句在 A-16 之后仍然成立,
但不再是读方交出上一代尾段的唯一途径:读方现在会在写方发布写头之后、换代之前,把本代已确认的帧先拷进自己进程内的
私有缓冲;换代之后,上一代尾段里这份拷贝覆盖的部分就从拷贝交出,不再查环 —— 所以「新一代已经写到同一环槽」的那些帧
(圈长略长于环长时,上一圈尾段在读到之前就被新一圈换掉)也读得到。原句只说了「环里还在的可读」,没说「环里没了的也可能
读得到」,对照代码会误读成读方只认环里的数据,所以补一条。

新增子条目(原句保留):

> [A-16] 措辞补充(读方语义,布局 / abi / 写方行为不变):读方可以在写方发布写头之后、换代之前,把本代已确认的帧拷进
> 读方进程内的私有缓冲。换代之后,只要新一代已发布的跨度整个在读方当前位置之下至少一个提前量、读方此后也没有跳变、
> 漏读或静止重读,上一代尾段就从这份拷贝交出 —— 环槽是否已被新一代换掉、在途写落在哪里,都不再影响这些帧;交出的是读方
> 拷贝时确认过的、写方为该位置写下的数据。新一代一旦发布到读方附近,这份拷贝立即作废;`write_head` 归 0、读方换绑时
> 同样作废。「覆盖」按代判、几何改写时上一代一律不读、段头 `channels` 不一致不读、失准口径,一概不变。

| 措辞 | 实现落点(`src/core/output/ShmRingMixSource.cpp`) |
| --- | --- |
| 写方发布写头之后、换代之前,拷本代已确认的帧 | `planPreCopy`:写头已确认、当前窗已锚定(锚点不是对着未确认写头下的)、写头不是 0、没有 flux 时,拷 `[max(锚点, 写头 − P), 写头)` 里还没拷的部分(每块至多 C 帧);`commitPreCopy`:与规则 7 同一次「acquire 栅栏 + epoch / 写头」复核,没换代、写头没往回走、写方前进不足半环才提交 |
| 读方进程内的私有缓冲 | `bind()` 第一次真绑定时(非实时线程、发布绑定之前)一次分配 2 × P × 2 个 float,P = min(构造参数(默认 2^17 帧), 环长 / 4);分配失败或构造参数 0 ⇒ 不拷不交 |
| 换代之后 …… 从这份拷贝交出 | `newGeneration`:当前窗降为上一代窗的同一刻、同一判据(正好隔一代、读方这一块没跳没漏读、上一代已锚定、写头不是 0),本代副本交接为上一代副本;`certify` 切出私有段,`read` 从副本拷进调用方缓冲,私有段不进拷贝后复核 |
| 新一代已发布的跨度整个在读方当前位置之下至少一个提前量 | `read` 的闩死判定:新一代已发布的最高写头 + λ > 本块起点(λ = min(P, 实测提前量上界 + 本块长);没量到过提前量也算)⇒ 副本作废,本代不再打开 |
| 读方此后没有跳变、漏读或静止重读 | `read`:读方跳了 / 漏读了 / 静止重读 ⇒ 上一代副本作废;漏读 / 静止重读 ⇒ 本代副本也清空;`sameGeneration` 同代写头回退 ⇒ 本代副本清空 |
| `write_head` 归 0、读方换绑时同样作废 | `clearWindows`(写头归 0、`onRebind` 都经它)清两个副本 |
| 其余一概不变 | 当前窗 / 上一代窗的认证、在途保护 `inflightGuard`、别名判据 `prevAliasFree`、新一代跨度下界 `aliasRef` / `spanBound`、段头 `channels` 比对、`countFailure` 一字不改 |

安全论证(详见 `ShmRingMixSource.h` 头注「读方预拷贝」):拷贝区间在写头之下(先写数据后发布写头,写头之下都已完整可见),
下沿是写头 − P,本代在途写都在写头之上、踩的是 [写头 − 环长, …) 的槽,P ≤ 环长 / 4 时与拷贝区间不相交 —— 不需要知道在途
写有多少、有几笔;换代由拷完那次 epoch 复核挡住。交出的每一帧都是读方观测时写方为该位置最后一次已发布的写入(例外:
停走带静止重写读方看不出来的那一形,头注 RP8),而且是读方自做副本那一遍的数据(A-3 oracle 的 I1'(a)(b) 判据,全部族
0 违例)。依赖:arm64 上「新一代的数据不先于这次 epoch+1 被读方看见」靠 B 线 M04 在 `AudioRing::bumpEpoch` 之后加的
release fence(x86 天然成立)—— arm64 包只从含 M04 的树出。

**不属于契约、因此没写进 IPC_CONTRACT 的**:私有缓冲的容量与每块拷贝预算、`ShmRingMixSource` 的构造参数(0 = 关,测试与
紧急回退用)、五个进程内计数(`privateRead` / `privateFrame` / `preCopyFrame` / `preCopyDiscard` / `privateLatchOff`,只计数、
不报警,不进桥面)。
