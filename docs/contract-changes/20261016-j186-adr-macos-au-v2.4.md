## 变更内容

### ADR-001(插件形态)

- 标题追加「v2.4/J186 增补发布格式与平台」。正文各条不动,新增一条「**发布格式与平台**」:Windows x64 发布 VST3(三个插件);
  **macOS arm64(Apple Silicon,最低 macOS 11)新增 VST3 + AU,首批 macOS 产物为 beta**。同一 CMake 目标加 `AU` 格式,**不新增主目标**;
  三插件目标 / `PLUGIN_CODE`(`Scvi` / `Scvo` / `Scvm`,厂商码 `Snch`)/ BUNDLE_ID 不变;macOS 产物不签名不公证(用户自行 xattr);
  不支持 Intel / Rosetta / GarageBand;**Logic 未实测、不作支持承诺**(与 README 的「beta / 未在 Logic 实测」口径一致,不更强也不更弱);**不做 AAX**。
- **冻结 AU 三元组**:`aufx Scvi Snch`(Input)/ `aufx Scvo Snch`(Output)/ `aufx Scvm Snch`(Monitor),首个含 AU 的公开发布后不可改。
- **冻结 AU 参数 ID 的派生方式**:与 VST3 同源(ParamID 字符串散列;`JUCE_FORCE_USE_LEGACY_PARAM_IDS=0`、`JUCE_USE_STUDIO_ONE_COMPATIBLE_PARAMETERS=1`,
  两宏由根 `CMakeLists.txt` 一处给出),与 123 参数面同一冻结点;回归判据 `tests/core/test_au_param_ids.cpp`。
- 「beta」只描述首批 macOS 产物的发布属性,**不把 beta 固化为永久状态**。

### ADR-011(技术栈与质量门)

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 工具链 | MSVC 静态 CRT(对齐 Bridge) | Windows:MSVC 静态 CRT(对齐 Bridge);macOS:Apple clang,arm64,`CMAKE_OSX_DEPLOYMENT_TARGET=11.0` |
| UI | WebView2 静态 loader | Windows:WebView2 静态 loader;macOS:系统 WKWebView |
| pluginval | strictness 5(`--skip-gui-tests`)进 CI | 句末追加:macOS 同强度,三插件 × VST3 / AU 共 6 次(清单以 `build-macos.yml` 为准) |
| 警告 | `/W4`(MSVC)+ `-Wall -Wextra -Wpedantic` | 追加:macOS 同用 `-Wall -Wextra -Wpedantic`,Apple clang 一方源码零警告 |
| macOS 质量门 | (无) | 新增一条:clang 一方零警告构建、ctest(12 条)、`auval -v` ×3(判负)、`auval -strict -v` ×3(单列,**只记录、不判负**;pluginval strictness 5 对 `.component` 自带的 auval 子项跑的正是 `-strict`,所以实际已随 pluginval 入门)、pluginval strictness 5 共 6 次(判负)、Output GUI pluginval 一次(**只记录、不判负**)、`scvb-auhost`(进程内 / 进程外)、打包冒烟;**mac job 失败只提示、不阻塞 Windows 出包**;Windows 门禁(gate 1-8)口径不变 |

数字取自 mac CI 实况(`build-macos.yml` 与 run 38708566079 日志)。宪法里写「门禁清单以 `build-macos.yml` 为准」,免得每改一个 CI 步骤就再修一次宪。
