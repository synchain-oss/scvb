## 变更内容

**一句话**:给 `min_segment_ms` 补上「两层生效」的定义句 —— 这是**文档对齐 + 把用户预期
变成真的**:修法落地前引擎只在 ① 层实现;② 层(段表兜底)由本卡补上。

| 面 | 改前 | 改后 |
| --- | --- | --- |
| PARAMETERS.md 定义句 | 无(只有 state 镜像行) | 补「两层生效」定义句(见上:含整条时间线/选区的限定,以及「存在相接自动邻段」这个成立条件) |
| 引擎行为 | 段表里可有 < MIN SEG 的 auto 段(跨轨交叠切出的独立区间产物) | 短 auto 段并入同轨**时间相接**的相邻段(优先前一段,值取被并入段;单段保留;用户段/锁定段不参与) |
| 区间图 / §5 指派 | — | 零变化(候选 D 边界:只收敛段表,不重切区间、不为指派重造输入) |
| 用户可见 | MIN SEG=2000 重分析后段表仍有 0.21s 的段 | **整条时间线重新分析后,段表里不再有「短于它、且存在相接自动邻段」的自动段**;两侧都不相接的孤立短段(窗边裁剪,或邻段因与手动段冲突而整条落选)按设计保留(带 E/C 角标的手动段不算) |
| 判据(`HOST SL414 (c)`) | 写回窗形态**一格都没有** —— (a)(b) 的写回窗 = 整条覆盖区,裁剪是恒等变换,「裁剪在兜底之后」这条语序照不出来 | 写回窗左端切进首段内部、裁出 **1000ms 残段**(< MIN SEG 2000ms)且与窗内下一段**相接** ⇒ 段表**两段**:残段**保留**、pan/vol 仍是**它自己的**(不是邻段的);它是「裁剪在兜底之后」的**唯一删除式落点**(把 `survivors` 改回存裁剪几何 ⇒ 该格红在「两段」与「残段值不变」上) |

**产品后果(如实登记)**:交叠区间里指派解出的那一段双轨分槽值(定谳实测 −60/+60)随并入
被丢弃,交叠期两轨都落到**邻段的值** —— 两轨在并后的区间里可能**同槽**(同 pan)。这是
裁定候选 D 时明确接受的代价:短段是杂音口径下,保住两轨的完整覆盖比保住 210ms 的分槽
平衡更符合预期;定谳 §4.2 同时记录了被否掉的区间层规则 A/C 会级联吞掉邻轨整段覆盖。

**为什么走变更文档**:定义句落在冻结文档 PARAMETERS.md 内。按 CLAUDE.md §5,冻结文档的
任何改动(哪怕只是把既有实现写清楚)都随实现 PR 记录在本文件里并挂 `status/frozen-contract`。

## 兼容性影响

- **state / 工程**:零影响。`min_segment_ms` 的编码、值域(50..2000)、落盘([SL-411])
  一个字节未动;旧工程打开后该参数语义即为本定义句所述,无迁移、无回落。
- **自动化参数**:零影响(state-only,123/124 口径不变)。
- **桥面 / 页面**:零影响。`setSegmentation` 入参与 `scvb.state` 载荷行未动;页面端
  `restoreWindowTooShort`([SL-399 R31] 的短段闸)不受本卡影响。
- **行为面(用户可感知)**:仅「重分析产出的段表」—— 整条时间线重分析后,**短于 MIN SEG 且
  存在相接自动邻段**的自动段消失(并入邻段,值取邻段);两侧都不相接的孤段照旧保留(选区/范围档
  重分析的窗边残段 [SL-399 R8],以及邻段因与手动段冲突整条落选留下的孤段)。
  撤销栈行为不变(并入发生在 `applyAnalysisSegments` 组表阶段,仍是一次分析一步撤销)。
- **行为面 · 已知反例([SL-417],**选区/范围档专属、整条时间线重分析不受影响**)**:写回窗端点
  落在一条**本身就短于 MIN SEG** 的产物内部、而它**相接的邻段整条落在窗外**时,那条邻段已被
  `clippedT1 <= clippedT0` 丢出 `survivors` ⇒ 兜底只能把它并进**窗内**那一侧、并取那一侧的
  pan/vol;而全量分析会把它并进**窗外**那条。用户可感知的形态是「选区开头那一小段的 pan/vol
  与全量分析解出来的不同」—— 它是 [SL-399]「写回窗内段表 == 全量分析在该窗内的样子」的
  **一个已知反例**(不是本卡引入:第 2 推之前同形态下结果逐字节相同)。要真对齐得让兜底看见
  窗外的相接邻段 —— 那是 [SL-399] 的设计面改动,行为面**另立 SL-417 封存**,未补用例。
- **既有判据**:`[SL382]`(50/120/500/1000/2000 单调不增)与 `HOST SL391` 在定谳 §4.3
  已论证为 no-op,实跑确认照旧绿;`buildGlobalIntervals` 直测零变化(区间图不动)。
