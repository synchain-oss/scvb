设计盒结论
Output 1180 × 780 · Input 460 × 560
1080×720 的内容区只有 1044×536，装不下 Tab2 的 14 列控件（状态灯 / Ch+ST / label / pan / width / 推子 / 电平 / 优先级 / 主唱锁 / 音量豁免 / 参与 / 配对 / 冻结×2 / 启用）。加宽到 1180 才够横向呼吸；780 高把内容区抬到 596px。15 行 × 44 = 660，1× 下仍需垂直滚动 + 表头 sticky——这是密度方案的前提，不是可绕开的。
Input 通道卡排布
4 × 4 紧凑网格 + 组胶囊排
16 张卡（未分配 + 01–15）铺满 4×4，428px 内宽下每张 100×40。组选择器 A–H 压在通道区顶行、比卡片矮一档，在线组带绿点——低频操作不抢主任务。改组确认条复用释放确认条组件（琥珀），展开时暂隐远程摘要行以守住 560px 设计盒。
Tab2 密度 · 两版
全列滚动（推荐）/ 行尾抽屉
两版都在稿里，用右侧 Tweaks 的「Tab2 密度方案」切。全列滚动版 15 列全展开、1× 可视 11 行，一屏内能横向比较所有轨的配置——15 轨的场景里这个更重要。行尾抽屉版主行只留 pan/width/vol/电平，次级配置收进「⋯」，行更疏朗但要点两次才能改配对。我选全列滚动：轨道页是配置页不是监看页，横向对比价值高于呼吸感。
logo 方案 · 三版（38×38 图标块内，stroke 1.6 / #21212A）
A · 声像弧
两道同心声场弧 + 中心点。直译「把人声摆在立体声弧上」，和 pan 旋钮、曲线编辑器的角度域同构。最贴产品语义。
B · 推子阵列
三支不等高推子。与 Bridge 家族的仪表气质最近，在 16px favicon 尺寸下也读得出。缺点是通用，任何混音插件都能用。
C · 天平支点
「Balancer」的字面像：一根横梁架在支点上，两端是左右声道。概念最清楚，但天平这个符号在音频里没有历史，读起来偏商务。
当前 header 用的是 B 的变体（Input）与一个角度盘（Output）——两个插件用不同图标是刻意的，让用户在 DAW 插件列表里分得清。若你选定一版做家族标，我把两侧统一成同一枚、再用一个小角标区分 IN / OUT。
