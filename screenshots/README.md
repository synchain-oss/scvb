## 三个背景/字色试稿(**请从这里选一个**)

三张都把页面渐变整体提亮了(用户原话「背景浅一点」),差别在**字**:

| 文件 | 改了什么 | 取舍 |
|---|---|---|
| `uih-1A-settings.png` | **只**提亮背景,字色字体全不动 | 改动最小;但底一浅,原来的灰字对比度就更勉强 |
| `uih-1B-settings.png` | 提亮背景 **+ 正文字色加深**(`--txt-1/2/3` 各深一档) | **推荐**。字与底的分离度回来了,而且没换字体,不引入任何字形风险 |
| `uih-1C-settings.png` | 在 B 的基础上**正文字体换 Inter** | Inter 在小字号下的中西混排更齐;但换字体会牵动整页排版密度,风险最大 |

选的时候主要看两处:左侧「使用说明」正文,和右下「诊断」表的等宽小字 —— 那两块是全界面
字号最小、最考验对比度的地方。
